# Módulo ABS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar no MOP 2.1 a importação automática da `BASE_ABS.xlsx`, persistência auditável, cálculo mensal de absenteísmo e página ABS protegida por perfil.

**Architecture:** Um agente Python iniciado pelo Agendador do Windows observa a planilha SMB, confere sua versão a cada 5 minutos e chama RPCs seguras do Supabase. O banco guarda solicitações, cargas e registros normalizados; a aplicação React consulta uma RPC mensal e invalida a visão quando uma importação termina. Supabase Auth substitui a validação de senha no navegador para tornar RLS e autorização por perfil efetivas.

**Tech Stack:** React 19, TypeScript, Vite 6, Vitest, Testing Library, Playwright, Supabase/PostgreSQL, Python 3.12, `openpyxl`, `watchdog`, `pytest`, PowerShell/Agendador de Tarefas do Windows.

**Spec:** `docs/superpowers/specs/2026-09-29-mop-abs-design.md`

## Global Constraints

- A fonte é `\\192.168.0.115\Shared\Relatorios_Quality\MIS - Operações\VR\ABS\BASE_ABS.xlsx` e nunca pode ser alterada pelo agente.
- O monitor inicia no logon, consulta solicitações administrativas a cada 30 segundos, confere a base a cada 5 minutos e exige duas leituras estáveis separadas por 10 segundos.
- A chave idempotente é `data + matrícula normalizada`.
- O vínculo de negócio é `BASE_ABS.re → mop_collaborators.matricula`; cliente, operação, supervisor e ilha vêm do MOP.
- `Declara` e `Ates` mapeiam para `FJ`; HOME/OFFICE são exibidos como `P`.
- ABS é `faltas / (presenças + faltas)`; denominador zero produz `0%`.
- O perfil `VISUALIZADOR` não pode ler ABS; apenas `ADMIN` vê o botão `Atualizar`, cria solicitação, reprocessa e acessa diagnóstico técnico.
- O servidor local de desenvolvimento usa a porta `3010`, pois as portas 3000, 3001 e 3002 pertencem a outros sistemas.
- Não incluir service role, senha ou segredo no bundle React, nos testes, nos logs ou no Git.
- Preservar alterações preexistentes do worktree e fazer commits restritos aos arquivos de cada tarefa.

## Review Focus

- Datas do Excel com deslocamento de fuso não podem trocar o dia de competência; Task 3 fixa serial, `Date` e texto no horário de São Paulo.
- Uma base regravada no mesmo dia não pode duplicar registros nem apagar a última carga válida; Tasks 2 e 4 testam assinatura, `upsert` e falha parcial.
- Matrículas numéricas, textuais, com espaço ou zero à esquerda devem conciliar de modo previsível; Tasks 2 e 3 testam normalização e pendência.
- Alterar URL/estado no navegador como `VISUALIZADOR` não pode liberar dados; Tasks 1 e 6 testam sessão, guarda e RLS/RPC.
- Marcadores desconhecidos e linhas incompletas não podem virar presença ou falta silenciosamente; Tasks 3, 4 e 5 exibem pendência e mantêm `-`.
- Um arquivo SMB alterado enquanto ainda está sendo gravado não pode gerar carga parcial; Task 4 testa estabilização, trava e recuperação pela varredura periódica.

```ts
export async function signInWithMatricula(raw: string, password: string): Promise<User> {
  const matricula = raw.trim();
  const { data, error } = await supabase.auth.signInWithPassword({
    email: `${matricula}@mop.local`, password,
  });
  if (error || !data.user) throw new Error('Matrícula ou senha incorreta.');
  const { data: profile, error: profileError } = await supabase
    .from('mop_users').select('id,matricula,nome,email,role,status')
    .eq('auth_user_id', data.user.id).single();
  if (profileError || !profile) { await supabase.auth.signOut(); throw new Error('Perfil não encontrado.'); }
  if (profile.status !== 'ATIVO') { await supabase.auth.signOut(); throw new Error('Este acesso está inativo.'); }
  return profile as User;
}
```

`AuthProvider` restaura a sessão via `getSession`, observa `onAuthStateChange` e expõe `{ user, loading, login, logout }`. Remover de `LoginPage` a chamada `db.getUsers()` e toda comparação de senha no navegador. Em `vite.config.ts`, usar `{ port: 3010, strictPort: true, host: '0.0.0.0' }`.

def load_config(env: Mapping[str, str]) -> Config:
    required = ("ABS_FILE_PATH", "SUPABASE_URL", "SUPABASE_SERVICE_ROLE_KEY")
    missing = [key for key in required if not env.get(key)]
    if missing:

    return Config(Path(env["ABS_FILE_PATH"]), env["SUPABASE_URL"], env["SUPABASE_SERVICE_ROLE_KEY"], 500, 30, 300)
